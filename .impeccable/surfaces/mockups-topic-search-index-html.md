# Topic search — functional 5B mockup

Operate mode. Extend the approved subject-search proposal inside the existing web identity. User explicitly requested execution after choosing the proposed flow; no unresolved product choices block this isolated prototype. No production changes, source traffic or real case mutations.

## Direction contract

THESIS: A familiar search leads from an everyday subject to precise procurement records and quoted pages. Record rows and contextual evidence carry the interface.

OWN-WORLD: Existing forest and ivory palette, Bricolage headings, IBM Plex body, thin separators, green committing actions. Light default supports daytime reading; dark theme remains available. Restrained color.

STORY: Type a topic, narrow the scope, distinguish title matches from document passages, open the exact page, save a passage and its source to a browser-local demonstration investigation.

FIRST VIEWPORT: Brand/navigation above a generous 42px question, full-width search and compact filters; count-bearing result switches; a wide reading column and narrow coverage/context column. First records are visible without scrolling on desktop. A document match opens a source reader without losing the query.

FORM: Code-led extension of the user-approved 5B proposal, using existing search, evidence drawer and document-reader conventions. No concept seed: the flow and incumbent visual world are already selected. Signature interaction is highlighted search phrase → exact page → preserved quotation.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Boundaries

All procurement records and reference PDFs are explicitly fictional. Source links resolve to local reference material, never invented SEAP records. Geographic filter selects an explicit county or locality identity; commune selection includes its child village. Counts derive from fixtures; document coverage excludes unprocessed files. Search and drafts remain local, with honest storage failure handling. PDF binaries derive from the exact reader page content. Scope state persists in the URL; saved cases persist only in this browser. Accessible dialogs, empty/loading/error states, mobile and dark mode are required.
