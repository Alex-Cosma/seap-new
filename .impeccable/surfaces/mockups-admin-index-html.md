# Admin collection mock-up

Mode: Operate. Extend the established cinecâștigă forest/ivory interface with a standalone, code-led interactive admin preview. User explicitly requested a quick sketch before implementation, live collection statistics and editable pacing/related variables. No production integration, source traffic or actual configuration writes.

## Direction contract

THESIS: Show whether collection is safe and advancing, then let the administrator inspect or change its rhythm. Avoid a wall of unrelated metric cards.

OWN-WORLD: Existing Bricolage/IBM Plex typography, ivory background, forest-green emphasis, quiet rules, tabular numerals. Orange reserves attention for intervention.

STORY: Read global state and next request; compare the three recovery streams; inspect a request; change a staged configuration with an explicit apply action. Distinguish collected, processed and published.

FIRST VIEWPORT: Compact branded header and admin navigation. One wide live-state band with pause control, a single statistics row, then stream progress at left and editable pacing at right. Publication and request log continue below. On mobile, stack without horizontal page scrolling. Signature interaction: delay edits immediately update estimated rate, but active pacing changes only on Apply; no surprise request.

FORM: Precisely requested admin extension, directly shaped without a concept tournament or seed. Fixed global concurrency of one, shared SEAP budget and no automatic PDF crawling. All counts and scenario states are explicitly simulated. Inherit DESIGN.md; no new visual world.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
