# Document formats, large files and resumable OCR — 11 October 2026

Owner requested Word/Excel/archive support and recovery of documents rejected for size/page count, preserving investigative usefulness and originals. This continues [the P7S repair](p7s-recovery-20261011.md).

## Implementation

- Source GET uses the existing isolated browser, proxy, cookies, referer and POST→GET sequence. Browser sends <=64KiB chunks to Node with backpressure; no whole-file base64/Buffer. Regular production downloads have no fixed byte ceiling. Explicit bounded pilot limits still apply. Download deadline is600seconds, other SEAP requests remain45seconds; source admission rates, per-IP pacing and concurrency are unchanged. Local storage failures are audited without disabling healthy proxies or globally blocking collection.
- Originals and prepared PDFs are SHA256-addressed in PostgreSQL, using immutable1MiB chunks and an atomic metadata+chunks transaction. Existing inline blobs remain readable. Public original/PDF responses stream ranges; archive storage dashboard and public handover export/restore include chunk data. Migrations0069/0070 add storage metadata/chunks/preparation/contents and bigint request byte counters. No rewriting of archived originals or existing published documents.
- PDF, DOC, DOCX, XLS, XLSX, ZIP, RAR,7z and nestedP7S supported by detected content. CMS extraction retains the previous explicit cryptographic-verification status. Archive paths are never used as disk paths, symlinks and traversal entries are skipped and listed. Entries retain source names and resulting PDF page ranges in a manifest.
- Office conversion is an **offline text rendition**, not a facsimile. No macros, scripts or external relationships run. DOC uses antiword; DOCX uses bounded XML parts; XLS uses xlrd; XLSX uses read-only openpyxl, with formula strings and cached values explicitly distinguished. ReportLab renders a searchable PDF. Images/embedded objects/layout are not included; reader states this and links the exact original. PDF archive members retain their original page visuals, merged in manifest order.
- Unsupported archive members are explicitly listed; partial coverage is visible beside the document and in the reader. Archives which cannot be safely read fail explicitly, never silently treated as complete. Resource bounds:1000entries,8nesting levels,2GiB expanded bytes across archive layers in one document,768MiB/tool onLinux,85CPU/90wallseconds per tool. Python converters have their own limits as well. Protected/corrupt/unhandled formats still require the original or further implementation. These are processing protections, not a blanket original-download size limit.
- PDF text/OCR checkpoints after every page. A job yields after25pages or roughly2minutes of page work, requeues without counting as a failure, and resumes the prepared PDF/pages. No150page or100kcharacters/page rejection; PDF page count bounds the public page API. Incomplete text is excluded from public reader/search/evidence until all pages complete. Published results remain immutable; previous frozen quotations are untouched. New quotations include the relevant archive member/rendition provenance.
- Reader uses direct page entry rather than an enormous select. Collapsible bounded-height contents links to member page ranges, with conversion/omission notices. Existing public reading and authenticated SEAP-fetch policy stay unchanged.
- Four processing lanes remain. Production host observed32GiB total,~19GiB available; document container ceiling increases4→6GiB to accommodate bounded converters plus ten browser sessions. Disk observed313GiB used/654GiB available,33%; transfer/materialization checks2GiB free-space reserve. No new proxy or rate settings.

## Recovery

`node apps/web/node_modules/tsx/dist/cli.mjs apps/web/scripts/documents/recover-formats.ts` is read-only by default. `--apply` requeues only known automatic failed **file** jobs with old format/size/page/text/P7S errors and no processed result/active duplicate; records full before-state and IDs in `documents-formats-recovery` audit. Retained originals are processed locally; originals absent due to the old50MiB limit need a new download through normal gates. It does not touch the separate9inventory identity failures, unrelated interrupted jobs, completed results or collection settings. Queued means eligible to attempt, not guaranteed successful.
