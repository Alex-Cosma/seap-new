# Population peers and a group the reader can edit

Mode: Operate, refinement of the approved comparison page. User decisions: population is primary for local governments and counties; propose the closest10; show actual population differences; cities and municipalities can mix; allow explicit manual additions/removals. Budget matching is deferred.

THESIS: Explain why each administration is beside the focal one, and let the reader take control of the comparison without losing evidence.

OWN-WORLD: Preserve existing forest/ivory, Bricolage and IBM Plex, native fields, thin dividers, dark theme and source drawer. No new global tokens or visual identity.

STORY: Begin with the nearest10 by official census population → read population/date/source and differences → open “Personalizează grupul” inline → find and add/remove comparators → inspect recalculated measures → save the exact chosen roster, population evidence and contracts in Anchete. “Revino la sugestii” restores the explained automatic method.

FIRST VIEWPORT: Existing entity heading and year/CPV/channel form, then a group receipt describing population basis and a visible customization button. Focal population is beside its identity. Member rows show population, signed percentage difference and recorded acquisition value with their source action. Inline search reserves height while loading; mobile keeps names, population and actions readable in stacked rows.

FORM: Code-led refinement. A functional population-and-selection HTML sketch precedes application UI edits. Signature interaction: adding or removing one named administration updates the declared group and its median, and the saved comparison preserves that exact choice. Draft year/category changes remain explicit Apply; choosing a comparator updates the currently applied group.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Data: official versioned RPL2021 source, not unversioned legacy population. Closest means absolute population difference with deterministic tie-breaking; no spend/count eligibility filter. All chosen zero-source members remain visible as unavailable observations and do not become zero-spend peers. Median declares its actual observed member count. Missing/ambiguous population prevents automatic matching but manual selection remains available. Manual additions need not have population data and are explicitly labelled. County councils use official county totals, not a sum of incompletely linked authorities. V1 captures retain old semantics; V2 binds method, catalog version, identities, chosen roster and all exact source records.
